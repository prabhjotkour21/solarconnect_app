    - Home Consumption (W)

    - Grid Power (W) — importing or exporting

    - Consumption Today
    - Grid Import Today
    - Grid Export Today
- Economic Benefits Card:
    - Savings today (₹)
    - Total savings (₹) — lifetime
- Environmental Benefits Card:
    - CO2 saved (kg)
    - Trees equivalent
    - Coal avoided

    - Total kWh generated (lifetime)
    - Total CO2 saved (kg)
    - Total money saved (₹)

  - GET /api/energy/today          → daily totals (kWh)
  - GET /api/energy/accumulated    → lifetime totals
  - WebSocket (or polling)         → live data refresh every 5 seconds
  DATA MODEL (EnergyReading):
    timestamp, solarPowerW, consumptionPowerW, batteryPowerW, gridPowerW,
    batteryPercent, batteryCharging, solarTodayKwh, consumptionTodayKwh,
    gridImportTodayKwh, gridExportTodayKwh
